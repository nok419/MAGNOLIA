# 必要な画面遷移や演出など
webアプリとして開発する
ここで全ては書き尽くせないかもしれないが、「何もないところをクリックしたら今見ていたパネルを閉じる」「ボタンにカーソルを合わせると強調される」などUIUXに気を使い、優れたゲーム体験になるよう設計したい。

## タイトル
- 藍色ベースのシンプルな背景。パーティクルや時々入るグリッチなど、控えめな動きを持つ
- 中央にタイトルロゴ「MAGNOLIA」。少し強弱する柔い発光エフェクト
- 下部にボタン配置（ボタンのデザインは後述）
    - new game
    - continue
    - option
    - exit
- `option` はタイトルからでも開ける。ここでは settings タブのみを表示し、保存項目はゲーム開始後まで非活性にする
- `new game` を押すと 3 つのセーブスロット一覧を開く。空きスロットは開始、使用中スロットは上書き確認に進む
- `continue` を押すと使用中スロットのみを選べる一覧を開く。セーブが 1 つもない場合は非活性表示にする

## ゲーム開始前の演出
- タイトル画面がフェードアウトする
- システムメッセージ風演出「rebooting system」
- 小さな状態灯、数値レジスタ、波形スコープを持つ機器コンソール風の表示にする
- 色は最小限にし、異常や入力待ちなど意味のある部分だけを明るくする
- 各行は一瞬で消さず、数秒かけて順に表示する

## ゲームプレイ（チュートリアル前）
- 「再起動」ムービーを経て、2dマップ上に自機が配置される
- 登場直後は黒背景と自機だけの時間を作り、その後に視界範囲を明滅しながらゆっくり戻す
- 操作可能になる直前に自機が一度だけ発光し、広範囲に薄い波を出す
- 装備画面は開始直後から開ける。初期OSとして「破損」が装備されており、最低限の装備変更だけが可能
- `破損` の間は探索HUD、通信強度バー、ミニマップ、全体マップは解放されない。装備変更の導線だけが有効
- 最初は常設の status や minimap は出さないが、左下のヘルプテキストだけは表示する。マップ全体は広いが、最初のエリアだけが白く光る正方形の境界で囲まれ、その外へは移動できず、視界も制限される
- 「移動を制限しています」のような説明テキストは出さず、境界の見た目だけで伝える
- 制限中も camera と視界円の基本的な見え方は通常探索と同じにする。光の境界は world 上に常時見えていてよく、「まだ外へ出られない」状態が分かるようにする
- 初期通信と初期アイテムは、制限エリアの内側で自然に見つかる位置に置く
- 最初の通信「グッド・モーニング」のみがエリア内にあり、これに接続するのが最初の動線
- 隠しサブアームを初期エリア内のどこかに配置しておいてもいいかも
- map 上の調査物を取得した時は、その場で取得内容を短い popup で表示する

## チュートリアルミッション「グッド・モーニング」
- 緩やかな敵と弾幕配置
- 適宜操作方法のtipsが出る
- クリア後にシステム「os: magnolia」を獲得
- 2dマップに戻り、装備画面で初期OS「破損」から `os: magnolia` へ換装して閉じると、数秒の操作不能演出に入り、境界線の一辺へ camera が寄る。光の束のような境界がほどけ、その後に camera が戻ってエリア制限・視界制限が解除される
- 解除後は、通信の強度を示すバー、自機周辺の探索済みの箇所を表示するミニマップ、装備アイコンや今いるエリアの情報（名前・解放率など）を示すパネルなどの基本uiが表示される


## 2dマップ画面
- 探索空間は、エリアごとに切り替わる別画面ではなく、1 枚の大きなマップとして連続して移動できる
- エリアは「通信や調査対象が密集している地点のまとまり」として扱い、現在地に最も近いクラスター名を status に表示する
- 画面は巨大マップ全体を縮小表示せず、自機の周辺だけを camera で切り取って表示する
- camera は自機に少し遅れて追従する
- 自機の周囲には淡く明滅する視界円を常時表示し、その外側は少し暗く描写する。視界円は現状より広めに取り、画面上で見えていた範囲は minimap と全体マップにも探索済みとして残るようにする
- 左上に「今いるエリア名（解放していれば）」「解放率」「装備アイコン」を示すパネル
- クラスター間の通路や空白地帯では、どのエリアにも属さない状態があり得る。その間は area 名を出さず、通信や調査対象を探す移動区間として扱う
- 操作は `WASD` で移動、`Enter` で通信接続、`E` で装備画面、`M` で全体マップを開く
- `M` の全体マップは `os magnolia` 装備後に解放する。未解放の間に押した時は、短い `locked` popup のみを表示する
- 右上に円形のミニマップ。自機周辺の探索済みの箇所を表示する
- パネルとミニマップの間に横長長方形の通信強度バー。周波数計は「近くのミッションとの距離」強度計は「未開放の最も近い通信との距離」に応じて強度が変化する
- 補助システム「コンパス」装備時のみ最も近い「未開放通信を1つ以上残しているエリア」を示すコンパスをつける
- 画面左下に控えめなヘルプテキストを常時表示する。移動キー、通信への接続、装備画面を開くキーを表示する
- 発見済みエリアはグリッドや背景描写で強調される。通信はアイコンで示され、通信アイコンに対しインタラクトすることで通信を接続（シューティングに移行）できる。過去に未接続の通信は灰色で、接続履歴があるが復元率または解析率が100%出ない通信は白色で、完全に復元された通信は青色で表示される
- 一度探索して記録された地形、エリア、通信、調査対象は、その後は map / minimap に残る。現在の視界円の外にある時は少し薄く暗く描写し、未発見のものだけを表示しない
- 装備入手や調査対象のノードは、通信とは別系統のアイコンで表示する
- クリア済みの通信にも再挑戦できる。その場合、復元率の元になる聴取成功区間は過去の挑戦を累積した状態から続く
- エリア解放率は移動距離ではなく、そのエリア内の各通信について「開いた基本情報の割合」と「本文復元率」を 50:50 で合成し、その平均値として扱う

## 戦闘終了後のリザルト
- リザルトは右パネル内ではなく、戦闘画面中央の overlay として表示する
- 解析率、復元率、自己修復ポイント、新規に聴取できた時間を大きく表示する
- 新規入手装備がある場合は一覧で表示する
- 余計な説明文は出さず、必要な情報は入手装備一覧と数値だけで伝える

## アーカイブ・装備画面:
    淡いホワイトが基調の画面。装備タブとアーカイブタブ、設定タブがある
- アーカイブタブは最初から開けるが、未開放通信は一覧にも本文にも出さない

### 装備タブ:
    - メイン装備、サブ装備、os、subsystem 2 枠を装備できる画面
    - 取得済みの装備品から選択できる。未装備の箇所は「---」と表示される
    - 左側に装備スロットのリストがあり、現在装備中の装備名とアイコンが入る。選択する際の強調表示など、平坦なuiuxにならないように注意。装備スロットを選択すると右側にそのカテゴリの装備品一覧が表示される。装備品を選択すると詳細情報uiが表示され、決定ボタンで装備する
    - リストでない部分をクリックすると選択解除し通常の表示状態に戻る
#### 装備情報ui
後述する通信ログuiと共通の（少なくともある程度一貫性がある）見た目を持つようにする。
基本情報:
- 装備名
- 装備区分（メイン装備、サブ装備、os、subsystem）
- 効果説明
- 将来的に可能であれば、選択された装備のプロモーション動画を再生するuiも表示する。
- 本文としてのフレーバーテキスト
- 未入手かつ入手経路が purchase ではない装備は、名称・説明・本文を `???` として隠す

#### 装備システムについて
装備はフレーバーではなく、シューティングや探索のゲーム体験を左右する実質的な実装である。


### アーカイブタブ
    - 訪れたエリア・通信の内容を見返すことができる
    - 左側にエリアのリスト（各エリア内の通信の解放率も表示）、右側に選択したエリアの通信ログ一覧。それぞれのリストはただ要素を列挙するだけではなく視覚的にリッチなリストにすること。特に右側は上下に回転するようなホイール的なリストにしたいなぁ
    - 通信ログを選択すると右側が通信リストから、ログuiに切り替わる。選択されたリスト表示をヘッダーに、パネル表示で「通信タイトル」「送信日時」「発信者」「宛先」「復元率」が基本情報として、メッセージ本文がスクロール可能なテキストエリアに表示される。いずれも開放済みの部分しか表示されない（タイトル、送信日時、発信者、宛先は解析率で、メッセージ本文はノイズを受けなかった区間のみ表示）
    - 復元率は「ダメージを受けずに聴取できたメッセージ区間の割合」であり、撃破によって変動する「解析率」とは異なることに注意
    - pcのウィンドウのように、複数のログの詳細画面を出すこともできる
#### 通信ログui:
    基本情報パネル
    - 通信タイトル
    - 送信日時
    - 発信者
    - 宛先
    - 復元率
    メッセージ本文パネル
    - 聴取ずみのメッセージ本文
    - 再生、一時停止、ジャンプ、巻き戻しなどが可能なプログレスバー
    - 読み上げを使わなくてもログを見れる。読み上げを使うと、現在箇所がハイライトされる。

### 設定タブ
    - 音量（master, bgm, se, voice）。7段階的で選択可能な、離散化されたバー。なんて言えばいいのかな
    - キーコンフィグ
    - `key visual` ボタン。タイトル背景、グリッチ付き MAGNOLIA ロゴ、戦闘描画を使った現在のキービジュアルを modal 表示する。タイトル画面の option から開いた settings でも利用できる
    - セーブ。3 つのスロットを表示し、現在スロットへの保存と別スロットへの複製保存ができる。ロードはタイトル画面の continue から行う
    - タイトルに戻る
    下部に以下のスイッチui
    - 明滅を抑える
    - 難易度（穏やか・終末）
    - フレームレートを下げる（デフォルトではオフ）

## マップ画面
左右で3:7程度に分割する
- 左にエリアのリスト表示。リストを明示的に選択していないときはマップは自機中心。エリアをリストから選択するとマップがそのエリア中心にクローズアップされる。
- 右にはマップ表示。マップ上には自機、エリア、通信の位置が示される。未探索の箇所は暗く表示されるが、全体マップでは接続可能な通信アイコンは表示対象とする。特定の通信を選択するとその通信の情報（アーカイブタブと共通の、通信ログui）が表示される。その下のwarpボタンを押すと、自機がそのエリアに移動しマップが閉じる（専用演出）。warpせず何もないところをクリックするとログuiを閉じる。
- リスト表示の項目をクリックすると、マップ表示の対応するエリアがハイライトされ、その通信が選択される。
- 現行実装では、左にエリア一覧、右に全体マップと選択情報パネルを持つ。通信をクリックすると簡易情報と archive / warp の導線が出る。

## シューティング画面
一般的な縦スクロールstgのような画面構成。画面は左を広めに取り、概ね 7:3 で分割する
- 左側（ゲームプレイエリア）
- 右側（ゲーム情報エリア）


### ゲームプレイエリア
各ミッションの敵配置・弾幕の性質や設定、全長などのデータは後々 05_データ構造で定義
- 自機、敵機、敵弾、背景、エフェクトなどを描画する
- 画面下部周辺に特定のサブ武器のクール状況などを表示することもある
- 自機を操作してシューティングをするゲーム画面

### ゲーム情報エリア
上部に基本パネルを設置。
- プログレスバー（通信終了までの残り時間）
- 解析率（撃破率）
- サブアームのストックやクールダウン情報
- スコア表示
中段に通信パネルを表示
- 聞き取れた部分の通信が字幕で表示される。字幕は流れていく。聞き取れなかった部分（被弾してノイズが走った箇所）は字幕にもノイズが走り読めない。
- 下段にtips（操作方法）として移動、メインショット、サブアーム、設定のキーコンフィグを再確認できるようにする
- 戦闘中の操作は `WASD` で移動、左クリックで main、`click 2` で sub、`Shift` で精密移動とする

- データ構造は 05_データ構造で触れるけど、ダメージを受けた区間（通信が欠損した箇所）は、復元率の計算に影響するだけでなく、ログでどこをダメージを受けたかを示すのにも使うので保存の仕組みがいるね
