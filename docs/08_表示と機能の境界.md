# 08_表示と機能の境界

更新日: 2026-04-26

## この文書の目的

- フロントエンドチームとアート&デザインチームが、見た目や演出を変えても機能を壊しにくい境界を明示します。
- mission ごとの演出調整を、独自関数ではなく content と renderState の範囲で進める前提を固定します。

## 正本

- gameplay の正本
  - `packages/game-session`
- save / settings / import-export の正本
  - `packages/persistence`
- 表示の正本
  - `apps/web`
- 描画に渡してよい値の正本
  - `packages/game-session/src/runtime-types.ts`

## 見た目側が安全に変更できる場所

- `apps/web/src/components/*`
- `apps/web/src/screens/*`
- `apps/web/src/styles/global.css`
- `apps/web/src/app/canvas-markers.ts`
- `content/gameplay/missions/*.json`
  - 敵出現時刻
  - 敵編成
  - generic override
  - hazard の位置、時間、移動
- `content/gameplay/enemies/*.json`
  - HP、挙動種別、弾パターン参照
- `content/gameplay/bullet-patterns/*.json`
  - cadence、burst、rotation
- `content/gameplay/projectiles/*.json`
  - speed、noiseDamage、見た目 preset

## 直接触らない前提の場所

- `apps/web` から repository を直接読む変更
- `apps/web` から session 内部状態へ直接触る変更
- 画面側で missionId を見て独自にゲームルールを分岐する変更
- mission ごとに TypeScript 側へ専用関数を足して敵配置や弾幕を定義する変更

## 拡張手順

1. 見た目だけで足りる場合
   - `apps/web` の component / style を変更します。
2. 表示に必要な値が足りない場合
   - `runtime-types.ts` に renderState を追加します。
   - `game-session.ts` で renderState を組み立てます。
   - snapshot の組み立てだけで済む場合は `session-snapshots.ts` を更新します。
   - UI はその追加フィールドだけを読みます。
3. gameplay 調整の場合
   - まず `content/gameplay/*.json` で表現できるか確認します。
   - 既存の generic schema に入らない場合だけ、contracts → loader validation → session の順で拡張します。

## 敵配置と弾幕のルール

- mission の違いは、基本的に `waves` と `hazards` の差分で表現します。
- 敵の細かな差分は `EnemySpawn.overrides` の許可済みキーだけで表現します。
- 現在 loader が許可している override は次です。
  - `speed`
  - `driftX`
  - `wobbleAmplitude`
  - `wobblePeriodMs`
  - `pauseAtY`
  - `pauseMs`
- 新しい表現が必要なら、まず generic なキーとして追加し、特定 mission 専用の処理は避けます。

## save と UI の注意

- settings 変更は `changeSetting` command 経由でのみ行います。
- 装備購入、強化、装着、アーカイブ選択、mission 開始は session 側で検証します。
- `saveToSlot` は「別スロットへ複製して保存」です。現在操作中のスロットは切り替えません。

## 現行の画面・描画境界

- `MenuScreen.tsx` は tab と画面合成だけを持ちます。
- 装備、アーカイブ、設定の各表示は `apps/web/src/screens/menu/*Panel.tsx` に置きます。
- `BattleCanvas.tsx` は canvas 要素の初期化だけを持ちます。
- 戦闘の描画順、描画 registry、個別の描画関数は `apps/web/src/components/battle-renderer.ts` に置きます。
- 戦闘の effect 適用、弾生成、弾移動、爆発処理は `packages/game-session/src/battle-effects.ts` に置きます。
- CSS の入口は `apps/web/src/styles/global.css` です。実装は画面単位の CSS ファイルへ分け、変更対象の画面に対応するファイルを編集します。
