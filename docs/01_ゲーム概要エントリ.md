# MAGNOLIA

## 概要
文明が滅びた終末世界。
通信システム「MAGNOLIA」は現在も稼働を続け、人々が最後に残した通信とメッセージを受信している。

現行の playable slice は、チュートリアル開始から `mission_evacuation` クリアまでです。`mission_good_morning` クリア後は `mission_where_are_you` と `mission_evacuation` が順不同で開放されます。詳細は `07_スライス定義.md` を参照してください。

プレイヤーは通信システム MAGNOLIA として電子空間を探索し、各地に残された通信基地や民間放送が残した通信に接続する。通信には私的な伝言、業務放送、自動送信など複数の通信が束になって残されており、プレイヤーはそれらを解析し、失われた声や記録を復元していく。探索は2dマップで行う。

特定の基地や通信に接続すると、画面は一般的な縦スクロールシューティングに切り替わる。
シューティングパートでの目的は敵を倒すことそのものではなく、通信を妨げるノイズを除去し、メッセージを最後まで聞き取ることにある。

シューティングパートではメッセージの内容が常に再生されている。敵弾や接触は瞬間的な雑音として作用し、被弾すると音声に砂嵐が混じったり、再生速度が乱れたりして、メッセージの聴取状態が悪化する。一方敵機はそのもの通信帯域を汚染するノイズ源であり、撃破することで通信の解析率が上昇する。敵弾は「自機だけを狙う攻撃」ではなく、ノイズ源が無差別に放射している可視ノイズとして扱う。そのためプレイヤーは、ノイズ源を除去して解析を進めるか、安全を優先して聞き取りを守るかを判断しながら立ち回ることになる。

クリア時の解析率に応じて、アーカイブに残る内容が変化する。十分に解析できた通信は、送信時刻、発信者、宛先、通信タイトルなどの基本情報が解禁される。内容そのものは、復元率に応じて断片的にしか分からない場合と、ほぼ完全に保存される場合がある。

このゲームでは、世界が滅んだ理由そのものを説明し切ることよりも、誰かが最後に残した声や、役目を終えてなお働き続ける通信システムの静かな情緒を重視する。催花雨と同じ世界観を共有しつつ、こちらでは「出会い」ではなく「残響の受信」を主題とする。

## ゲームシステム概要
- 2Dマップを探索し、接続可能な通信を探す。基本的にはシンプルに表現された平面の2dマップを自機が動き回る。特定の区域は「通信基地」や「通信施設」としてマークされており、その周辺には複数の通信が残されている
- UIは通信の反応を示すコンパスとミニマップ、装備アイコン+α。なるべくシンプルに。
- 縦スクロールシューティングでは敵弾を避けて通信記録を聴きながら、ノイズ源の撃破を目指す
    - 敵機を除去して解析率を上げ、敵弾を避けて聴取状態を保つ。撃破は解析率に、回避は聴取状態に関わる
- 通信の解析率に応じて基本情報が、復元率に応じて音声と本文がアーカイブに追加される
- 得た装備や情報をアセンしつつ、新たな基地や通信束を探しにいく
- 装備は「自己修復ポイントによる購入」「通信成功の報酬」「2Dマップ上での発見」の3ルートで入手する
- 2Dマップ上には自己修復ポイントや隠し装備など、探索で見つかる収集要素が配置されている
- 自己修復ポイントを消費して装備のレベルを上げられる。自己修復ポイントはスコアとは別の通貨である
- 全体設定で「穏やか（calm）・終末（terminal）」の難易度を選べる。各ミッションにも個別の危険度がある

## 通貨とスコア
このゲームではスコアと自己修復ポイントを分離する。

- スコア: 1ラン内のパフォーマンス指標。解析率・復元率・行動から算出する。自己ベスト記録用であり、消費しない
- 自己修復ポイント: 装備の購入・レベルアップに使う持続的な通貨
  - 入手源: ミッションクリア報酬（初回ボーナスが大きい）、新規 heardRanges の増分、2Dマップ上の収集、特定の敵のドロップ
  - 同じミッションを繰り返しても、既に聞いた範囲からは自己修復ポイントがほぼ得られない（新規 heardRanges ベースで算出するため）
  - 新しいミッションの初回クリアやマップ探索で主に獲得する設計とし、同じミッションの繰り返しだけで稼ぐ構造にはしない

## ミッションの流れ
通信に接続すると、以下の流れでミッションが進行する。

1. 導入 (intro): 余白から始まる。接続演出の後、戦闘画面に遷移する
2. 再生中 (playing): メッセージ本文が再生され、その長さに合わせて敵が出現する
3. 余韻 (outro): メッセージ終了後、少しの余韻時間を残す
4. 報酬画面 (result): オーバーレイで報酬画面が表示される（スコア、自己修復ポイント獲得量、解析率、復元率など）
5. 帰還: 2Dマップに戻る

## 被弾と聴取状態
自機には HP がなく、死亡もない。被弾は「聴取状態の悪化」として現れる。

- 被弾や敵との接触が起きると、ノイズ強度（0.0〜1.0）が上昇する
- ノイズ強度が聴取閾値を超えている間、その時間帯は `damageRanges`（聞き損ねた区間）として記録される
- ノイズ強度は時間とともに自然減衰するが、被弾し続けると通信が全く聞こえない状態が続く
- 被弾後および近接攻撃の直後には一定の無敵時間があり、連続被弾を防ぐ
- 一部の補助装備は「被弾したとき」を発動トリガとして持つ

「失敗はない、ただし聴けなかった部分が増える」

詳細は `06_音声管理.md` を参照。


操作要素の最小構成
- 通常ショット
    - ノイズ源を除去する基本手段
- サイドアーム（stgにおけるボムのようなもの）の選択肢
    - 安定化
        - 近距離または短時間の雑音除去
        - 敵弾や局所ノイズへの対処に使う
    - 解析波
        - 通信環境を一時的に改善する
        - 広範囲のノイズ低減や聴取状態の立て直しに使う
    - 静音域
        - 一時的に安全なエリアを作る
        - 聞き取りは安定するが、解析は進めにくい
- その他プログラム・強化要素の例
    - 時間経過で解析率が上がっていく
    - 特定種別のノイズを受けない
    - ショット強化
    - 2d探索時に通信基地の位置をより正確に当てられる
    - サイドアームのクールダウン減少


通信の情報例（解析率で解放度合いが変化）
* 発信種別
* 送信局名
* 送信日時
* 宛先
* 通信タイトル

通信内容の例:
* 私信
    * 誰かに宛てた最後の言葉
    * 送れなかった謝罪や近況報告
* 業務放送
    * 気象、保守、避難、資材配分などの定時連絡
    * 避難誘導や状況報告
* 自動送信
    * 誰もいない基地から繰り返される機械音声
* 保守記録
    * MAGNOLIA の修理、同期、障害対応に関する断片
    * 研究施設の内部放送が漏出したもの
